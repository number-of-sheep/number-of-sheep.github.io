우리 연구실은 Synopsys 툴을 IDEC에서 제공받아 사용합니다. 이때 기본적으로 다운로드 가능한 툴들에 추가적으로 사용하고자 하는 기능이 있을 경우 Synopsys SolvNet 홈페이지에서 다운로드합니다.

선배가 현재 있는 Raphael과 SPX를 다시 설치해 달라고 요청해 주셔서, 이번 기회에 다운로드 방법을 정리해 보았습니다. 해당 다운로드 방법은 Synopsys SolvNet 홈페이지의 Downloads에서 원하는 툴을 선택하면 나오는 가이드와 동일한 내용입니다.

### 다운로드 전에
다운로드는 FTPS 프로토콜을 이용하여 진행됩니다. 이를 위해 `lftp`라는 명령줄 기반의 FTP 클라이언트를 사용합니다. 이미 설치되어 있을 수 있으니, `lftp` 명령어가 작동하는지 확인해보고, `Command not found` 에러가 뜬다면 아래 명령어로 설치합니다.
```bash
yum install lftp -y
lftp
```
`lftp`를 설치했음에도 불구하고 실행이 되지 않을 경우 `/usr/bin/lftp` 경로에 `lftp`가 존재하는지 확인해보세요.

### 다운로드 방법

1. 터미널에서 아래 명령어를 입력하여 서버에 접속합니다.
    ```bash
    lftp -u <username> eft.synopsys.com
    ```
2. 비밀번호를 입력하여 정상적으로 로그인되었다면, 다운로드하고자 하는 툴의 경로에 접근합니다.

    > 이때, 아래와 같은 에러가 뜰 수 있습니다.
    > ```bash
    > cd: Fatal error: Certificate verification: Not trusted
    > ```
    > 이 에러는 서버의 SSL 인증서를 신뢰할 수 없다는 의미입니다. 이를 해결하기 위해 `lftp`에서 SSL 인증서 검증을 비활성화할 수 있습니다. 다음 명령어를 입력하여 SSL 인증서 검증을 비활성화하세요.
    > ```bash
    > set ssl:verify-certificate no
    > ```

3. `ls` 명령어로 현재 디렉토리의 파일 목록을 확인한 후, 다운로드하려는 파일을 선택합니다.
    ```bash
    get <filename>
    ```
4. 다운로드가 완료되면, `exit` 명령어로 `lftp` 세션을 종료합니다. 이후 `lftp`를 실행했던 경로에 다운로드된 파일이 저장되어 있을 것입니다.

5. 다운로드된 파일들은 기존 방법대로 Synopsys tool installer를 이용하여 설치할 수 있습니다.

### 툴별 다운로드 경로

- Raphael: `/site26351/MyProducts/rev/raphael_fx_vV-2023.09`
- SPX: `/site26351/MyProducts/rev/sen_proc_exp_vV-2023.09`
- Sentaurus, HSPICE: IDEC에서 제공하는 서버를 이용함

### 환경변수 설정

툴을 다운로드한 뒤에는 반드시 해당 프로그램의 경로를 path에 추가해 주어야 합니다. 우리 연구실에서는 회사별 환경변수 설정을 `.cshrc` 파일에 추가하여 관리하고 있습니다. 이번에는 Synopsys 툴들을 설치했으니 아래와 같이 환경변수 설정을 추가합니다.

```shell
setenv RAPHAEL_HOME <path_to_raphael>
setenv SPX_HOME <path_to_spx>

set path = ($RAPHAEL_HOME/bin $path)
set path = ($SPX_HOME/bin $path)
```

이렇게 별도의 파일로 관리하면 서버에서 아래 명령어를 통해 간단하게 환경변수를 불러올 수 있습니다.

```shell
source <path_to_cshrc>
```
